# tristan ai — demo page

This is a simple static demo page with a dark purple/pink background gradient and a centered rounded text box.

How to view

Option 1 — Open directly
- Double-click `index.html` in your file explorer or open it from your editor's Live Preview.

Option 2 — Serve locally with Python (recommended for some browsers)
- In PowerShell, run:

```powershell
# from the project folder
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Notes
- The page uses a Google Font (`Inter`). An internet connection will fetch the font.
- If you want tweaks (different hues, larger card, form elements inside the box), tell me what you'd like and I'll update the styles.
